# WPIncidentLens — mapa wymagań i stanu implementacji (T-002, aktualizacja po M2 i części M3)

**Data:** 2026-11-12. **Stan kodu:** gałąź `main`, commit `6c4cc87` (po scaleniu PR #30, #31, #33 i #32); wiersze bazy danych (§6 oraz C06–C08, C10, R-02, P3–P6, N1–N8, S-10–S-11, Q-01) zaktualizowano na commicie `0febf3d` (po scaleniu PR #38 i #39, M3 / T-301). **Źródło wymagań:** `docs/WPIncidentLens_Specyfikacja_Senior_PoC_2026-11-09.md` (kolumna „Spec”).

Mapa opisuje **stan obecny**, nie plan. Numery linii sprawdzono w kodzie commita `6c4cc87`: odwołania do wierszy, które M2 tylko przesunął, przeniesiono na podstawie porównania plików z commitem `4cac876` i przyjęto tylko tam, gdzie oba końce zakresu są tymi samymi wierszami; odwołania do kodu przeniesionego z `cli.py` do nowych modułów odczytano w kodzie. **Uwaga:** w M3 kod bazy przeniesiono z `cli.py` do `database.py`, `sqldump.py` i `dbrules.py` (commit `fd983fe`), więc odwołania `cli:NNN` w wierszach spoza bazy danych wskazują wiersze z `6c4cc87`, nie bieżące. Wiersze zaktualizowane w M3 wskazują moduły i funkcje zamiast numerów linii. Każdy wskazany test istnieje i został uruchomiony w pełnym zestawie (macOS, wynik zbiorczy w `docs/TEST_MATRIX.md`).

Skróty modułów: `cli` = `wpincidentlens/cli.py`, `ing` = `wpincidentlens/ingest.py`, `mod` = `wpincidentlens/models.py`, `mig` = `wpincidentlens/migrate.py`, `case` = `wpincidentlens/case.py`, `rep` = `wpincidentlens/report.py`, `files` = `wpincidentlens/files.py`, `fr` = `wpincidentlens/filerules.py`, `integ` = `wpincidentlens/integrity.py`, `wpd` = `wpincidentlens/wpdetect.py`, `fc` = `wpincidentlens/fileclass.py`, `an` = `wpincidentlens/analysis.py`. Moduły bazy (M3) są podawane pełną nazwą: `database`, `sqldump`, `dbrules`, `phpserialize`, `redact` (`wpincidentlens/<nazwa>.py`).

Skróty plików testów (`tests/test_*.py`): `cli` = `test_cli`, `pos` = `test_scenarios_positive`, `neg` = `test_negative`, `sec` = `test_security_inputs`, `inv` = `test_invariants`, `ing` = `test_ingest`, `prop` = `test_ingest_properties`, `mod` = `test_models`, `con` = `test_contract`, `mig` = `test_migrate`, `case` = `test_case`, `rw` = `test_report_writer`, `fr` = `test_filerules`, `integ` = `test_integrity`, `wpd` = `test_wpdetect`, `fc` = `test_fileclass`, `sql` = `test_sqldump`, `dbr` = `test_dbrules`, `ps` = `test_phpserialize`, `red` = `test_redact`. |---|---|
| IMPLEMENTED | istnieje kod **i** test, który sprawdza to zachowanie i przeszedł |
